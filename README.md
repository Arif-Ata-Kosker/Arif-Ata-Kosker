# Arif Ata Köşker

Arif Ata Köşker (Arif Ata Kosker) is a developer and content creator based in
İzmir, Türkiye, working on artificial intelligence and automation. He is the
founder of FeastFlows, an ordering and customer management system for
restaurants, and builds automation workflows, AI-assisted video pipelines and
live web applications for businesses. He publishes setup guides for the systems
he builds at arifatakosker.com/kaynaklar.

## What I build

- **Automation workflows** with n8n and API integrations
- **Live web applications** with Next.js and Supabase
- **AI-assisted video pipelines** with Kling and Remotion
- **Social media messaging flows** with ManyChat

## Projects

- **[FeastFlows](https://feastflows.com)**: ordering and customer system for
  restaurants. Multi-tenant, running with real restaurants and real orders.
- **[Resources archive](https://arifatakosker.com/kaynaklar)**: bilingual setup
  guides for AI tools. Every step verified against its own source, with the
  traps written down separately.
